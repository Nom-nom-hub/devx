# DevX File Icon for VS Code

A simple VS Code extension that adds a custom icon for `.devx` configuration files without changing your existing file icon theme.

## Features

- Custom icon for `.devx` files in the file explorer
- Syntax highlighting for YAML-based `.devx` files

## Installation

### From VS Code Marketplace

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "DevX File Icon" or look for the publisher "DevX-cli"
4. Click Install

### Manual Installation

1. Download the `.vsix` file from the [releases page](https://github.com/DevX-cli/devx-icon-theme/releases)
2. Open VS Code
3. Go to Extensions (Ctrl+Shift+X)
4. Click on the "..." menu in the top-right corner of the Extensions panel
5. Select "Install from VSIX..."
6. Choose the downloaded `.vsix` file

## Usage

After installation, the extension will automatically apply the custom icon to all `.devx` files in your workspace without changing your existing file icon theme.

The icon should appear immediately for all `.devx` files. No additional configuration is required.

## Icon Information

The DevX File Icon extension includes both SVG and PNG versions of the icon:

- SVG icon for vector-based rendering
- PNG icons in various sizes (16x16 to 256x256 pixels)

The icon is designed to be recognizable even at small sizes in the VS Code file explorer.

## Compatibility

This extension is compatible with all VS Code file icon themes. It only adds a custom icon for `.devx` files and does not affect any other file icons.
